# Site SindServ Porto Feliz

Site institucional estático e responsivo do Sindicato dos Servidores Municipais de Porto Feliz.

## Páginas e acessos
- Notícias: seção inicial para publicação de comunicados oficiais.
- Área do associado: https://portal.higestor.com.br/sindservpfz
- Convênios: seção de benefícios.
- Filiação online: https://app.higestor.com.br/inscricao/associado/sindservpfz

## Publicar com GitHub Pages
1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch padrão (normalmente `main`), pasta `/ (root)` e clique em **Save**.
4. Aguarde a publicação em `https://sindservpfz.github.io/sindservportofeliz/`.

## Domínio personalizado
O domínio `www.sindservportofeliz.com.br` não é gratuito por ser `.com.br`: precisa ser registrado e renovado com o provedor de domínio. Após adquirir o domínio, configure **Settings → Pages → Custom domain** e os registros DNS recomendados pelo GitHub. Não configure domínio sem controle do DNS.

## Autenticação e segurança
Este site não recebe nem armazena senhas ou tokens. Os botões levam o visitante ao portal Higestor por HTTPS. A autenticação é realizada pelo serviço externo; não há backend de login neste repositório.

## Pendências antes da divulgação
- Substituir o monograma provisório **SS** pelo arquivo original do logotipo oficial do sindicato.
- Validar os links externos da Prefeitura e Câmara.
- Publicar notícias oficiais aprovadas e confirmar condições atuais dos convênios.
- Configurar GitHub Pages e, se desejado, o domínio personalizado.
